# Install

## Requirements

- Minecraft 1.21.1.
- NeoForge 21.1.

Cartofold needs no other mod.

## Download

Download the mod from [Modrinth](https://modrinth.com/project/cartofold) or from the [GitHub Releases](https://github.com/nicolas-goyon/Cartofold/releases).

Modrinth has two channels:

- **Release**: the stable versions. Use these versions.
- **Alpha**: a build of each change of the development branch.

!!! warning
    Do not use an alpha in a world that you want to keep.

## Install the mod

Put the jar in the folder `mods`:

- **Single player**: on your computer.
- **Server**: on the server and on the computer of each player.

Cartofold is necessary on the server and on the client. The server records the exploration, and each player gets only the chunks that this player explored.

## Other map mods

Cartofold does not change the vanilla maps. It stays compatible with the mods that change them, for example ImmediatelyFast and Moonlight. Xaero's Minimap and Xaero's World Map can stay with Cartofold.
